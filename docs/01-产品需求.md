# 产品需求

## 背景与推导

一篇好读的段子并不自动成为好演的节目。铺垫、包袱和回扣依赖具体次序；改过一个词，旧段单与演出意见可能需要重听。工程保存未采用版本和真实手记，Agent准备与比较，创作者判断声音、节奏和观众反应，程序不裁定好不好笑。

生成成本和等待时间会变化，但固定作品、历史依据、具体意见与连续审阅仍需长期积累。固定工程避免让模型每轮重建结构；结构化数据与多种阅读方式共用同一专业成果。插件按需安装，让作者提出目标、Agent操作工程、作者在适合的工作面阅读和选择。

## 定义与首版

脱口秀工坊是河图洛书JS／TS专业插件。把素材、铺垫、包袱、回扣、不同段单和开放麦手记保存在同一可返工工程。用户包括独立作者、编辑与外部Agent。默认旅程：读取固定素材 → 拆分铺垫和包袱 → 明确回扣 → 比较节目段单 → 保存实际手记 → 固定备选局部返工 → 复核旧依据 → 节目本与下一稿。

首版包含完整专业维护、准确来源回读、并行方案、固定意见、专业状态和改稿影响、上下文、固定交接、JSON／Markdown／HTML工程及专业阅读本。功能必须经机器入口执行，作者可以自然语言提出目标，也保留人工优化入口。

## 边界

文风工坊拥有偏好与精修，有声剧拥有录音混音，本包维护喜剧材料、结构和演出手记。不提供观众预测、真人招募、录音识别、演员联系或对外发布。正文、正式设定、素材、采纳与定稿由宿主和作者掌握，不另建数据库、模型渠道或内部Agent。

成功以真实创作、审阅、返工及下一轮接续为准，安装、动作数或文件存在都不足以代表完成。开发与验收状态只由08维护。
