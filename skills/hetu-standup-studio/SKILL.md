# 脱口秀工坊

先发现当前已启用包、真实Schema和同包方法，携带确切WorkRef、management_ref及活动包／能力摘要。先读取固定作品、已有工程、来源、成果和意见，不重复创建或要求作者手填。

读取固定素材 → 拆分铺垫和包袱 → 明确回扣 → 比较节目段单 → 保存实际手记 → 固定备选局部返工 → 复核旧依据 → 节目本与下一稿。

素材固定来源并只追加；铺垫、包袱、追加包袱分别保留。回扣固定两端段子组合摘要，段单按独立出场核验铺垫先于回扣，重复段子不去重。改稿后旧回扣、段单、备选及意见明确待复核；局部备选使用完整段子摘要，其他段子原字节保持。开放麦记录保存固定段单快照与提交者手记，不把估时或模拟当真人观众反馈，不按笑声次数评判作品品质。

文风工坊拥有偏好与精修，有声剧拥有录音混音，本包维护喜剧材料、结构和演出手记。不提供观众预测、真人招募、录音识别、演员联系或对外发布。

[流程与反例](references/workflows.md)提供专业方法；[操作地图](references/operations.md)从正式清单生成。每阶段保存后回读固定修订；未知先get_operation，CAS保留原输入。用create_handoff接续下一阶段，正文采纳、定稿、外发与费用分别按确切作者决定。
