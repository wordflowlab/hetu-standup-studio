# Skill与机器接续

包内hetu-standup-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：读取固定素材 → 拆分铺垫和包袱 → 明确回扣 → 比较节目段单 → 保存实际手记 → 固定备选局部返工 → 复核旧依据 → 节目本与下一稿。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

素材固定来源并只追加；铺垫、包袱、追加包袱分别保留。回扣固定两端段子组合摘要，段单按独立出场核验铺垫先于回扣，重复段子不去重。改稿后旧回扣、段单、备选及意见明确待复核；局部备选使用完整段子摘要，其他段子原字节保持。开放麦记录保存固定段单快照与提交者手记，不把估时或模拟当真人观众反馈，不按笑声次数评判作品品质。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
